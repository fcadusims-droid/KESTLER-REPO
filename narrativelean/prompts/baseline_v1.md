# Tarefa: baseline — o prompt simples

Leia o documento inteiro abaixo e liste todas as contradições internas que
encontrar: datas, idades, contagens, regras do mundo, atributos, quem sabe o
quê e quando. Para cada contradição, cite literalmente os trechos que se
contradizem (pelo menos quatro palavras cada; as citações são conferidas
mecanicamente e as que não forem encontradas no texto são descartadas).

Não sugira correções. Não liste problemas de estilo. Se não houver
contradições, devolva uma lista vazia.

```yaml

      - "segundo trecho literal"
```
