# Ace Combat Minozis

*Ace Combat Minozis is a fan-made work, with no connection to Bandai Namco. Ace Combat and Strangereal belong to Bandai Namco Entertainment.*

*Ace Combat MINOZIS* is a spin-off fan project of the Ace Combat franchise, set in Strangereal in the decade between *Ace Combat 7: Skies Unknown* (2019) and *Ace Combat 8: Wings of Theve* (2029), with consequences reaching toward *Ace Combat 3: Electrosphere* (2040). These documents are the authoritative source for the project's story, world, characters, missions and game systems. Where any two documents disagree, the [Continuity Bible](CONTINUITY_BIBLE.md) is correct.
