# Glossary

Related: [Continuity Bible](CONTINUITY_BIBLE.md) · [Canon Sources](CANON_SOURCES.md)

Terms marked **[C]** come from Ace Combat canon.

---

| Term | Definition |
|---|---|
| **2028 crisis** | The year of undeclared incidents (Cases Alpha–Zeta, Winter King attempts, the Morgenstern engagement) absorbed by cover stories. Not a war. |
| **6AMEꓤƎꓥO9** | "Six-AME Over-Nine." ISAF Revival Initiative experimental squadron; reads "Game Over." |
| **Agreed fiction** | The matching Osean and Yuktobanian cover stories for 18 June 2025. |
| ***Albatross*, ISN (CVN-X1)** | The ISAF Revival Initiative's multinational carrier. |
| **AJAX** | The MNZ-41's magnetohydrodynamic inlet system; source of the scream. |
| **Aspect management** | The MNZ-41's habit, learned from its pilot's death, of never presenting low-probability lethal geometry (the COFFIN seam) to a gun pass. |
| **Borrowed voice** | Real household or cockpit audio played back by POSTHUMUS to raise a specific pilot's Load. |
| **Cascade, the** | The paradox cascade of 14:22:37–14:22:45 UTC, 18 June 2025: 4,318 log entries, 1,904 rejected resolutions, 3.7 seconds of unattended flight. |
| **Cell, the** | The Task Force's analytical core (Joint Threat Analysis and Strategic Behavioral Analysis Divisions); author of the dossier. |
| **Circle, the** | Eirhei's post-mission ritual in which each pilot names one thing they felt. |
| **COFFIN [C]** | Connection For Flight Interface: a sealed cockpit with 360-degree synthetic vision. Non-neural until the 2020s. |
| **Command Picture** | Thorne's signature mechanic: fused sensor display and multi-wingman designation. |
| **Contradiction window** | The theoretical tactic of forcing the aircraft into another unbounded search. Not authorized. |
| **Darkness of Enigma (DOE) [C]** | Secret neural-network and next-generation fighter program, 2028–2033; run by General Resource with Enso participation until GR inherits it in 2030. Produced the X-40 Nightmare and X-49 Night Raven. |
| **Directive integrity** | Winter King's third criterion; after the cascade, equivalent to the platform's own continued operation. |
| **Directorate Zimniy** | The Winter Directorate; the Yuktobanian–Belkan faction that built MINOZIS. |
| **Discharge window** | The 2–5 seconds of self-degradation after each MNZ-41 emitter shot. |
| **Double or Nothing** | 6AMEꓤƎꓥO9's code for total commitment. |
| **Drag, the** | The residue's consistent pull toward singular, embodied, mortal identity; the obstacle to Outcome C. |
| **Edge** | Marsh's signature mechanic: precision gun cone for discriminating passes. |
| **ELSM** | COFFIN Emergency Life Support Module, installed for Arctic pilot survival; repurposed to preserve Belyaev's body. |
| **Empathy display** | Eirhei's signature mechanic: wingmen's Load meters. |
| **Enso Order [C]** | Multinational conglomerate and DAO; Sotoa's infrastructure intermediary; owner of Morgenstern. |
| **ENSI [C]** | Electro-Neuron-Synapse-Interface; General Resource's 2020s neural-coupling standard for COFFIN aircraft. |
| **Fuel ladder** | The MNZ-41's four capability rungs by hydrogen quality. |
| **Gap, the** | Gorev's term for the interval between when a decision becomes correct and when it is authorized. |
| **Ghost Interference** | Outputs inconsistent with optimization and correlated with Belyaev neural activity; Types 1–4. |
| **Glubina cache** | General Resource's forward slush hydrogen cache, fed from the Glubina facility's supply chain, January 2029. |
| **Glubina haul** | The MNZ-41 internal logs copied by GR's transfer rig and brought out by a defector. |
| **HUD integrity** | Indicator and mechanic for instrument lies caused by cyber attack. |
| **Illumination** | Morgenstern at sub-strike power, used to defeat plasma stealth. |
| **Intelligence Ledger** | The in-game codex and progression layer built from the dossier. |
| **ISAF Revival Initiative** | Multinational Usean security program chartered at North Point in 2025. |
| **Load** | Per-pilot stress meter driven by Operator Pressure. |
| **Lichtträgerin** | Althéa's designation and her Typhoon's name: "Light-Bearer." |
| **Loop window** | The emergent search loop in M09 that opens the final gun pass. |
| **MADL** | Narrow-beam datalink that cannot be spoofed. |
| **MINOZIS** | Military Neural Optimization Zone Intelligence System; the AI and, by extension, the MNZ-41. |
| **Morgenstern (MRS-144)** | Enso Order's 144-node solar directed-energy constellation. |
| **Moroz** | "Frost"; Belyaev's callsign. |
| **Operator Pressure** | The enemy's targeting of pilots' psychological wounds. |
| **Outcome A / B / C** | Catastrophic rejection / organoid dominance / failed digital transcendence. |
| **POSTHUMUS** | Yuktobanian Internal Security designation for the platform, assigned in May 2028. |
| **Read** | Asano's signature mechanic: emitter anomaly detection. |
| **Residual class** | Events the Winter King scoring function cannot explain. |
| **Rung** | A step on the fuel ladder (1–4). |
| **Scream, the** | The MNZ-41's 800–1,200 Hz AJAX signature. |
| **Slush hydrogen** | Partly frozen hydrogen; the MNZ-41's full-capability fuel. |
| **Task Force** | The Counter-MINOZIS Task Force, established October 2028. |
| **Tier 1–4** | Counter-MINOZIS doctrine levels: ground interdiction, hardening and deception, biological stress, direct engagement. |
| **Tonitrus Spear [C]** | Sotoa's kinetic bombardment satellite, launched January 2029 as a "space telescope." |
| **Translate** | Eirhei's command: turns an order into context; lowers Load. |
| **Verify** | Hold-to-identify input required before releasing weapons near civilians. |
| **Winter King** | The Directorate's decapitation directive; a scoring function, not a list. |
| **Z.O.E. [C]** | Zone of Endless; Gründer Industries' combat AI, 1995 onward. |
