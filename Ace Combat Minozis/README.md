# MNZ-41 MINOZIS — Game Design and Narrative Documentation

*Ace Combat MINOZIS* is a spin-off fan project of the Ace Combat franchise, set in Strangereal in the decade between *Ace Combat 7: Skies Unknown* (2019) and *Ace Combat 8: Wings of Theve* (2029), with consequences reaching toward *Ace Combat 3: Electrosphere* (2040). These documents are the authoritative source for the project's story, world, characters, missions and game systems. Where any two documents disagree, the [Continuity Bible](REFERENCE/CONTINUITY_BIBLE.md) is correct.

Start with the [Project Overview](PROJECT_OVERVIEW.md).
